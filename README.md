# Godot_TopDown_Character_Controller

A character controller for top down movement, such as for an RPG game

## Installation

Make sure to download the ChillCube Developer tools: https://github.com/ChillCube/ChillCube-Developer-Tools.git

### Using the Godot Plugin
Enable the **ChillCube Tools** plugin, then paste the repo URL into the Clone tab.

### Linux / CLI
```bash
clone-gd-addon https://github.com/ChillCube/Godot_TopDown_Character_Controller.git
```

## Documentation
https://github.com/ChillCube/Godot_TopDown_Character_Controller/blob/main/DOCUMENTATION.md

## Deinstallation
Use the CC Tools panel in Godot, or run:
```bash
remove-gd-addon Godot_TopDown_Character_Controller
```
